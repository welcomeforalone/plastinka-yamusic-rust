# Android, этап «Настройки и аккаунт»: спецификация API

Единственный сетевой запрос этапа — аватар аккаунта. Основа — десктопная
реализация `src/api/avatar.rs` (та же логика и те же проверки). Живых
запросов для этой спеки не делалось; код MarshalX и других GPL/LGPL-проектов
не переносился.

## `GET https://login.yandex.ru/info?format=json`

- Паспорт Яндекс ID. Заголовок: `Authorization: OAuth <токен>` (тот же токен,
  что у API музыки). `X-Yandex-Music-Client` не нужен.
- Токен уходит только в заголовок: ни в URL, ни в лог, ни в текст ошибки.
- Нужные поля ответа:

```json
{
  "login": "user",
  "default_avatar_id": "12345/abc-DEF_1",
  "is_avatar_empty": false
}
```

- Адрес картинки: `https://avatars.yandex.net/get-yapic/<default_avatar_id>/islands-200`
  (размеры у yapic именованные, `islands-200` — 200×200). Хост всегда
  `avatars.yandex.net`, из ответа он не берётся.

### Проверки и крайние случаи (как на десктопе)

- `is_avatar_empty == true` — аватара нет, буква.
- `default_avatar_id` нет, пустой, `null` или не строка — аватара нет.
- Идентификатор годится, только если: длина не больше 128, нет `..`, все
  символы — латиница, цифры, `/`, `_`, `-`. Иначе (`../etc`, `a b`, `a?x=1`,
  `evil.com` и т. п.) аватара нет.
- Нет флага `is_avatar_empty` — не помеха.
- Ответ не 2xx, битый JSON, не объект, тело больше 64 КиБ, сбой сети —
  `null`: аватар необязателен и не мешает входу и проверке подписки.

### Использование в Android

- Запрос один раз, после подтверждения входа и Плюса (`AppViewModel.loadLibrary`);
  уже полученный адрес не перезапрашивается. Выход (`logout`) отменяет запрос и
  сбрасывает адрес.
- Адрес лежит только в памяти (`StateFlow`), не в `SharedPreferences`.
- Картинку грузит Coil с `diskCachePolicy(DISABLED)`: на диск ничего не
  пишется (кэш в памяти допустим). Пока картинка не загрузилась или не
  загрузилась вовсе — буква: первый символ имени аккаунта (`displayName`,
  при его отсутствии `login`), в верхнем регистре, как на десктопе.
- Правило проекта о картинках: на диск можно только метаданные и обложки;
  аватар мы на диск не кладём вовсе, как и десктоп.

## Источники

- `src/api/avatar.rs` (десктоп, наш код) — логика и тесты.
- Документация Яндекс ID (`https://yandex.ru/dev/id/doc/ru/`) — метод
  `login.yandex.ru/info`.

## Что проверить вживую

- Реальный ответ у аккаунта с аватаром и без него (`is_avatar_empty`).
- Что `islands-200` отдаёт картинку без токена.
