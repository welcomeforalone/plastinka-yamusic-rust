# Безопасность

## Как сообщить об уязвимости

Не открывайте публичный issue. Напишите через
[Private vulnerability reporting](https://github.com/welcomeforalone/plastinka-yamusic-rust/security/advisories/new)
(вкладка Security → Report a vulnerability). Отвечаем в течение недели.

Опишите, что происходит, как это повторить, на какой версии и системе. Не
присылайте свой токен Яндекса, логи с ним и данные аккаунта.

## Что считается уязвимостью

- токен Яндекса уходит куда-то, кроме доменов Яндекса, или попадает в файл,
  лог, текст ошибки или URL;
- обход проверки подписки или чтение чужих данных;
- «Слушать вместе»: подключение без сопряжения, расшифровка или подмена
  трафика между устройствами;
- автообновление ставит файл не из релизов этого репозитория или без
  проверки SHA-256;
- плагин отправляет данные не туда, куда описано в настройках;
- падение от данных из сети, которое можно вызвать удалённо.

## Как устроено

- Токен хранится только в системном хранилище паролей: Windows Credential
  Manager, Secret Service в Linux, Keychain в macOS, Android Keystore. Если
  хранилище недоступно, токен не сохраняется, запасного файла нет.
- «Слушать вместе» работает только в локальной сети: обмен ключами ECDH
  P-256, шифрование AES-256-GCM, звук и токен между устройствами не
  передаются. Протокол описан в [docs/api/sync.md](docs/api/sync.md).
- Обновления качаются только с GitHub этого репозитория и сверяются с
  `.sha256` из того же релиза.

## Поддерживаемые версии

Исправления выходят только для последней версии.
