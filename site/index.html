Для Linux — любой дистрибутив

Одна сборка без deb и rpm работает на Arch, CachyOS, Manjaro, Fedora 36+, openSUSE, Ubuntu 22.04+ и Debian 12+, под Wayland и X11.

Программа ставится в ~/.local/bin и появляется в меню приложений. Медиаклавиши и виджеты плеера работают через MPRIS, вход хранится в Secret Service (gnome-keyring, KWallet или KeePassXC).

Вопросы

Это безопасно? Куда уходит мой токен?

Вход идёт через Яндекс ID по коду устройства: пароль программа не видит. Токен хранится только в системном хранилище паролей (Windows Credential Manager, Secret Service, Keychain, Android Keystore) и отправляется только на серверы Яндекса. Код открыт, сборки делает GitHub Actions.

Нужна ли подписка?

Да. Plastinka проверяет Плюс после входа, без подписки музыка не играет. Это клиент для тех, кто уже платит за Яндекс Музыку и хочет удобную программу.

Могут ли заблокировать аккаунт?

Plastinka ходит к тем же адресам API, что и официальные приложения. Случаев блокировки мы не знаем, но гарантий дать не можем: это может противоречить условиям Яндекса.

Windows пишет «Система Windows защитила ваш компьютер»

Так SmartScreen встречает любую программу без платной подписи кода. Нажмите «Подробнее» → «Выполнить в любом случае». Файл собирается в GitHub Actions из открытого репозитория, контрольная сумма лежит в релизе.

macOS пишет, что разработчик не подтверждён

Приложение подписано ad-hoc, без нотаризации Apple. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
