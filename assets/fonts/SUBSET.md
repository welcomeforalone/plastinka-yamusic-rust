# Урезанный Inter

Шрифты в этой папке — Inter (SIL OFL 1.1, без зарезервированного имени), урезанные
до нужных символов: так бинарник легче примерно на 850 КБ. Глифов было 2937, стало
1546 в каждом начертании. Хинтинг, кернинг (GPOS) и подстановки по умолчанию
(`liga`, `calt`, `ccmp`, `locl`, `mark`, `mkmk`) сохранены. Все записи `name`
тоже сохранены (ID 16 и 17 нужны, чтобы SemiBold и ExtraBold находились как семейство
«Inter»). Убраны только названия стилистических наборов (ID 256 и дальше): самих
наборов в урезанном шрифте нет.

Символы, которых нет в урезанном шрифте (греческий, иероглифы и прочее), cosmic-text
берёт из системных шрифтов.

Оставленные диапазоны:

| Диапазон | Что это |
|---|---|
| U+0020–007E | Базовая латиница |
| U+00A0–00FF | Latin-1: «», ·, ×, °, буквы с диакритикой |
| U+0100–024F | Латиница: расширения A и B (польский, чешский, румынский, турецкий) |
| U+02B0–02FF, U+0300–036F | Модификаторы и комбинируемые диакритики |
| U+0400–052F | Кириллица и её дополнение |
| U+1E00–1EFF | Дополнительная латиница (вьетнамский и др.) |
| U+2000–206F | Пунктуация: тире, многоточие, кавычки, узкие пробелы |
| U+20A0–20CF | Знаки валют, в том числе ₽ |
| U+2100–214F | Буквоподобные: №, ™ |
| U+2190–21FF | Стрелки |
| U+2200–22FF | Математические знаки: −, ≤, ≥ |
| U+25A0–25FF | Геометрические фигуры: ▲, ● |

Как пересобрать из полного Inter (fonttools 4.68 во временном venv):

```powershell
python -m venv $env:TEMP\ft
& $env:TEMP\ft\Scripts\pip install fonttools
$u = 'U+0020-007E,U+00A0-00FF,U+0100-024F,U+02B0-02FF,U+0300-036F,U+0400-052F,U+1E00-1EFF,U+2000-206F,U+20A0-20CF,U+2100-214F,U+2190-21FF,U+2200-22FF,U+25A0-25FF'
foreach ($f in 'Regular','SemiBold','Bold','ExtraBold') {
  & $env:TEMP\ft\Scripts\pyftsubset "Inter-$f.ttf" --unicodes=$u --name-IDs='*' --name-languages='*' --name-legacy --output-file="assets/fonts/Inter-$f.ttf"
}
Remove-Item -Recurse -Force $env:TEMP\ft
```
